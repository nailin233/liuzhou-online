# 网上柳州 · 美术与视觉规范

## 设计原则

### 1. 真实优先，风格化为辅
- 优先使用真实地理数据生成建筑轮廓
- 在数据准确的前提下适度风格化
- 不可为了视觉效果牺牲地理准确性

### 2. 可识别的柳州特征
- 柳江水系要有清晰的视觉特征
- 重要地标建筑需要精细建模
- 体现柳州城市色彩和建筑风格

### 3. 性能与美观平衡
- 目标: 浏览器端稳定 60 FPS
- 多层次细节 (LOD) 系统
- 分块加载与卸载

## 视觉风格

### 初期白模阶段
- **建筑**: 简洁白模，带环境光遮蔽
- **道路**: 灰色平面，清晰边界
- **水系**: 蓝色平面，轻微反射
- **天空**: 渐变色或纯色背景
- **照明**: 环境光 + 平行光，模拟自然光照

### 中期细节阶段
- 添加建筑基础纹理 (墙面、窗户)
- 道路标线与人行道
- 树木与绿化 (程序化生成)
- 改进水面材质

### 后期成熟阶段
- 精细地标建模
- 动态天气系统
- 昼夜循环
- 季节变化

## 技术规格

### 模型规范
- **格式**: GLB/glTF 2.0
- **单位**: 米
- **坐标系**: 本地笛卡尔坐标系 (原点待定)
- **三角面数**: 
  - 普通建筑: < 500 面
  - 重要地标: < 5000 面
  - 交通工具: < 2000 面

### 材质规范
- **PBR 材质**: 基础色、粗糙度、金属度
- **贴图尺寸**: 
  - 普通: 512×512 或 1024×1024
  - 地标: 最高 2048×2048
- **压缩**: 使用 KTX2/Basis Universal

### 性能预算
- **Draw Calls**: < 200
- **三角面总数**: < 100万 (可见范围)
- **纹理内存**: < 200MB
- **帧时间**: < 16.67ms (60 FPS)

## 相机与控制

### 初期 (当前)
- **类型**: Orbit Controls (轨道控制)
- **目的**: 方便观察地图全貌
- **FOV**: 55°
- **距离**: 10-100米

### 后期 (玩家系统)
- **类型**: Third Person (第三人称)
- **跟随**: 平滑跟随角色
- **碰撞**: 防止穿墙
- **高度**: 1.5-2米 (眼睛高度)
