# 网上柳州 · MVP 需求

## 当前可交付目标
1. 验证柳州五星街周边可合法取得的道路、建筑轮廓数据覆盖率。
2. 建立真实地理坐标到本地米制 3D 坐标的可测试转换。
3. 使用 Three.js 展示来源可追溯的街区白模，可旋转观察并在后续加入角色。
4. 真实地理信息缺失时必须显示缺失，不得用随机白模伪装真实柳州。

## 暂不开发
多人、购物、AI NPC、付费、完整版城市、地铁与真实人物等。

## 验收条件
- `npm test` 和 `npm run build` 通过；
- 地图数据下载与许可记录完备；
- 实际街道路网与公开地图抽样比较；
- 所有 AI 修改通过 PR 经用户批准后合并。
